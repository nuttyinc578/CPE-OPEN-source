# Contributing to CPE

Thank you for helping improve the Cube Physics Engine.

1. Fork the repository and create a focused branch.
2. Keep commands inside the documented, bounded `CPE/1` protocol. Do not add arbitrary source-code execution.
3. Add or update tests for behavior changes.
4. Run the Python, Node.js, and Go tests described in `README.md`.
5. Open a pull request describing the change and how it was tested.

By contributing, you agree that your contribution may be distributed under the repository's MIT License.
