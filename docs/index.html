ONE ENGINE

Designed for games.
Observable by default.

01

Pymunk physics

Deterministic fixed-step rigid bodies, bounded numeric inputs, polygons, impulses, gravity, pausing, and snapshots.

02

Integrated particles

IPE emits, updates, caps, and renders particles alongside every physical body without a second service.

03

Health reports

CPE 0.2 exposes compact physics, particle, body-count, quality, and timing diagnostics for repair tools.

THE COMPLETE STACK

Speak from any side.

Commands stay data—not executable source. Node accepts requests, Java submits them, Go caches state, Aspire orchestrates services, and Python owns simulation and rendering.
