# Cube Physics Engine 0.2

CPE 0.2 is the open-source physics and particle runtime behind The Cube Beta Halloween Update.

- Unified Python and Node package version `0.2.0`.
- New `health_report()` API for game repair and bridge diagnostics.
- Pymunk physics and the Integrated Particle Engine in one runtime.
- Node.js command bridge, Go cache, Java client, and .NET Aspire orchestration.
- Standalone Windows executable, complete source bundle, SHA-256 checksum, and nightly.link artifact.
- MIT licensed.

Run `CPE.exe --offline` for the interactive demo, or `python -m cpe --version` to verify the installed version.
